System Architecture & Overview

This project is a full-stack database application designed to manage sports player metrics efficiently using modern RESTful communication patterns.

Key Features:

  • Asynchronous Data Processing: Uses JavaScript fetch() API for smooth CRUD operations without reloading the page.
  • Parameterized SQL Execution: Ensures security against SQL injection vulnerabilities in MySQL.
  • Clean Architecture: Completely decouples backend routing from presentation layer CSS styling.
